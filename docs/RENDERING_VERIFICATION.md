# 0.3.18 终端绘制验收

日期：2026-09-22。环境：本机 macOS、Electron 42.8.1、应用报告的显示器刷新率 120 Hz。

## 测量与边界

- 0.3.17 的普通输入基线已达到约 8.3 ms 的 rAF 帧间隔中位数；采样中的 51 次按键，到下一次 rAF 的第 95 百分位约 8.4 ms。没有发现锁定 60 FPS。
- 0.3.18 启用官方 WebGL 后，在变化文本连续滚屏的隔离负载中，中位数约 8.3 ms，第 95 百分位约 9.0～9.3 ms；初始化阶段曾出现长任务，稳态采样未出现。
- 这些结果不能证明刷新率翻倍，也不是按键到显示器像素呈现的端到端延迟。GPU 改动用于替换终端绘制后端，不修改系统屏幕刷新率，不解除垂直同步。
- 探针每 240 帧报告一次，只采集有焦点、可见窗口的时间与数量，不采集命令或主机内容。它和所有演示代码均不进入安装包。

## 可复现方式

```sh
npm run build
node_modules/.bin/electron test/native-preview.cjs --measure-frames --render-load
```

在窗口中连接演示组。第二台服务器生成 1875 批变化文本，每批 100 行、目标间隔 16 ms，约 30 秒；无需网络或真实服务器。只测普通输入可省略 `--render-load`，使用 `--slow-echo` 模拟 1.2 秒回显延迟。

## 验证范围

- Mac 窗口实测输入、退格、SSH 标签切换、进入 SFTP 后切回，原有输入保留，显示正常。
- 单元测试覆盖仅当前终端持有 GPU 渲染器、重复显示不重建、后台关闭不影响当前终端、初始化异常/上下文丢失回退和预显字距重算。
- GPU 驱动故障回退由可控桩测试验证，没有修改系统驱动或刻意中断用户的真实连接。
- 完整自动化测试共 196 项通过。没有测量或承诺真实服务器的网络延迟。
