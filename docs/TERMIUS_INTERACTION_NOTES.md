# 本地 Termius 交互观察

2026-09-09，观察本地 `/Applications/Termius.app`，安装版本 9.35.4。

## 实际观察

- 主机列表将左侧工具导航、顶部工作区标签、搜索与新建操作分层展示，主机卡片保持一致的图标和信息密度。
- SFTP 页先显示本机目录；远端未连接时只显示简洁的说明与选择主机入口。文件筛选、目录导航和文件操作分别安排，空状态不会像报错。
- SFTP 页面与主机页面使用独立的工作区标签；这类清楚的上下文边界值得保留。

以上来自界面操作和安装包版本信息，不是源码提取或算法分析。没有连接任何保存的服务器、读取凭据/私钥、升级软件，或复制 Termius 的代码、图标和品牌素材；也未测量其动画时长。

## 本轮在 ServerLink 的独立实现

- 继续保留本机与每台服务器的独立文件栏，状态变化只影响对应区域。
- 以 160～240 毫秒的短过渡强调侧栏、分组、弹窗、视图切换和连接就绪；终端输出不触发重复动画。快速操作会替换旧动效，系统“减少动态效果”时禁用。
- 使用 Electron 原生应用菜单定义 ⌘Q 退出、⌘W 关闭当前服务器，不依赖网页键盘事件；保留复制、粘贴与撤销菜单。
- ⌘W 不关闭本机文件页或整个应用窗口，模态框与传输中不误关；⌘Q 会结束所有连接，正在进行的传输也会停止。

没有引入账号同步、云凭据、订阅机制或新增 UI 依赖。
